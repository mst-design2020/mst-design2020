### Masaya Kato (M.S.T. Design, Saiki, Oita, Japan)

Independent researcher. I study how to check a small language model's answers from the outside: dictionary definitions, rules, retrieved sentences and a small NLI model, with the model itself doing only narrow jobs such as picking word senses. In the long run (AKANE Architecture), I want to hand this checking computation to physical parts such as p-bits.
